# Makon Marketplace · frontend-v2

Новая витрина и рабочий кабинет для существующего Spring Boot API. Backend находится в родительской папке и этим фронтендом не изменяется.

## Приложения

- Витрина покупателя: Next.js, `http://localhost:3000/ru`.
- Кабинет продавца и администратора: React + Vite, `http://localhost:4200`.
- Общий типизированный клиент API: `libs/api-client/src/index.ts`.

Для работы с товарами, корзиной и заказами нужен запущенный backend на `http://127.0.0.1:8080` и его PostgreSQL. Запросы `/api/*` проксируются приложениями на backend. В локальном профиле backend хранит загруженные фотографии на диске. Иллюстрации из `apps/client/public/products` служат запасными изображениями.

## Запуск

Из этой папки:

```bash
npm ci
npm run dev:customer
```

В другом терминале:

```bash
npm run dev:dashboard
```

Проверка сборки:

```bash
npm run typecheck
npm run build
```

Кнопки демо-входа заполняют поля тестовыми аккаунтами локальной базы. Для оформления заказа нужен аккаунт с ролью `CUSTOMER`; для управления магазином — `SELLER`.

## Текущий backend

Маршруты заказов продавца, отмена заказа покупателем и статусы резервов исправлены. Витрина использует API для товаров, вариантов SKU, корзины, заказов, избранного и отзывов. Кабинет работает с товарами, остатками и модерацией. Все 12 демо-товаров имеют загруженные фотографии; локальные иллюстрации показываются при отсутствии фото товара.
